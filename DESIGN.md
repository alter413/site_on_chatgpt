# Sova / Owner dashboard

Панель личного Telegram-ассистента. Главная задача — понять состояние и управлять
разрешёнными чатами без утечки данных между песочницами.

Направление: спокойный editorial SaaS; графитовая боковая панель, бумажный фон,
мятный акцент, тонкие границы, компактная типографика. Без стоковых иллюстраций.
Светлая/тёмная/системная тема; акценты mint/blue/amber; плотность comfort/compact.

Референсы структуры: плотная навигация Linear, иерархия operational dashboards.
21st CLI search проверен: каталог недоступен без авторизации. Используются собственные
компоненты и Lucide; внешние шаблоны/платная генерация не применялись.

Слева: обзор, песочницы, модели, активность, внешний вид, безопасность, справка.
Сверху: название раздела, обновление и ручной статус. Обзор: counters → график
активности → последние события и использование контекста. При отсутствии данных
честные нули и инструкции. Деморежим только явно помеченный, без внешних запросов.

Каждая кнопка работает: изменение статуса и песочниц через API, файловые формы,
смена модели и провайдера в памяти процесса, графики только по записанной телеметрии.
Реальная телеметрия хранит метаданные, без текста сообщений.

На мобильном боковая панель заменяется раскрываемым меню, сетки переходят в одну
колонку. Формы имеют labels, фокус видим, native dialog ловит фокус. Ошибки доступны
через role=alert, обновления через aria-live. reduced-motion соблюдается.

Безопасность: случайный пароль владельца, HttpOnly-сессия, проверяемая через базу бота,
общий лимит попыток и same-origin writes. Секреты живут в настройках Worker. Ненастроенное
приложение закрыто; демо не умеет обращаться к API управления.
